Platform · The Engine

It runs agents the way HR runs people.

One engine runs every agent we make, built to work the way an HR department does, so your company already knows how to run it. Every capability is denied until a rule allows it, every decision is recorded, and the hard calls go to a person. A new field is a new configuration, never new engine code.

Built like HR

Nothing new for your company to learn.

Every rule in the engine has a counterpart your managers already use. That is what makes it simple to adopt.

HIRED

Against a job description

Each agent has a role that names its duties, skills and tools.

BADGED

Only the access it needs

SUPERVISED

What it does

Control first. Then capability.

01

Default deny

Nothing is allowed until a rule allows it. Permits are granted for a reason, and lockout, health checks and a watchdog stop what shouldn't continue.

02

A record you can verify

A signed, hash-chained, append-only record of every attempt, approval and refusal. It is tamper-evident, can be exported, and is checked offline.

03

People make the calls

Rules are data, and the default is a person. The model never routes and never decides; approval modes are set only by a person.

04

A governed model pool

A fixed routing table chooses which model answers, with daily caps and stall guards. Only a person turns a model on or off, and every change says who.

05

Connectors on a short leash

Fixed endpoints, credentials by reference only, and every acting call behind an authorization.

06

Sends nothing home

It runs on your machine with your own models. There is no network code in the core.

Memory with a shape

Nothing is overwritten. Time is the truth.

Underneath every agent is an append-only memory. A replaced fact is kept and marked outdated rather than erased, and every memory can be found by who, what, when or where, then checked against its source.

Append-only

Every memory is written once and kept.

Cross-indexed

Find it by person, place, thing, time or meaning.

Checkable

Every memory points back to where it came from.

Analytics

Every agent's work becomes data you can see.

The engine stores what agents do in a structured, multi-dimensional form, not as flat logs. That makes advanced analytics possible across every agent, role and decision, shown as wave fields: live, moving views of where work, risk and approvals are building up.

It works like a workforce report for your agents: who is busy, where the hand-offs to people pile up, and what changed.

WAVE FIELDS

See patterns, not rows

Activity, approvals and refusals across the whole agent workforce, drawn as fields that rise and fall as the work moves.
