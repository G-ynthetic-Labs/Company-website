Platform · Verifiable Inference

Re-run any AI answer. Prove it hasn't changed.

AI models can give different answers to the same question. That's a problem when an expert has approved an answer and needs it to stay the one they approved. Verifiable Inference records an answer from an AI model running on your own computer, so it can be re-run later and shown to be identical down to the last character, or flagged if it isn't.

Talk to usPart of the engine
How it works

Answer twice, record it, check it any time.

  1. 01Fix the settingsSame model, same setup
  2. 02Answer twiceBoth runs must match exactly
  3. 03Record itA fingerprint, not the text itself
  4. 04Check laterAny change shows as a mismatch
What you get
  • Check more than AI answers: documents, software builds, datasets and model files.
  • A command-line tool that fits into existing build and release scripts, with no coding needed.
  • Optional checks that can block an answer before it's made, add extra confirmations or publish the record, without changing the answer.
  • A peer-review command that runs six tests designed to catch a false result, with evidence a reviewer can work out again.
  • No outside software needed, and 54 automated tests.
Sameness, not correctness

What it proves, and what it doesn't.

  • It proves an answer is the same answer, not that it's right. That is still the expert's job.
  • It needs an AI model on your own, unchanged hardware. Online AI services can't give this guarantee.
  • While it's on, each answer takes about three times as long.
