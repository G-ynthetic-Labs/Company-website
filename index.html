The problem we are solving

In regulated work, an unexplainable answer is not an answer.

Healthcare, finance, and defense cannot deploy a system whose reasoning is reconstructed after the fact by a second model guessing at the first one. Every mainstream interpretability method — SHAP, LIME, saliency — is post-hoc: it produces a plausible story about a black box it never had access to.

Memory has the same defect. Vector databases return nearest neighbours from a flat, opaque space. Nothing is addressable, nothing is inspectable, and nothing explains why one memory surfaced and another did not.

We attacked both from the substrate up. In our architecture the trace is the control flow that produced the output. The explanation isn't a reconstruction of the computation — it is the computation.

Ante-hoc, not post-hoc

A post-hoc explainer answers "what story fits this output?" Ours answers "what steps produced it, and where is each one recorded?" Those are different questions, and only the second one survives an audit.

Byte for Byte

It makes an expert's sign-off on an AI system stop expiring silently.

A qualified person validates an AI-assisted decision. Then a model tag is re-pulled, a driver updates, hardware is replaced — and the system gives a different answer to the same question. Nobody is told. The drifted system is not broken; it is perfectly self-consistent, so every health check stays green.

Two guards catch it: one proves the environment is stable now, the other proves it has not quietly become stable at a different answer since sign-off. It stands alone, wraps a model you already run, and has no dependencies.

How a thought moves through the system

Seven stages. Each one leaves a record.

  1. Decompose

    Input is projected onto an explanatory basis — by default seven rhetorical arcs: essence, form, frame, function, intent, relation, value.

  2. Score & cohere

    Each arc receives an investment score, measured against a per-model calibrated baseline, then passed through three coherence phases.

  3. Rank & plan

    Arcs are ranked by influence; that ranking drives the tool chain the system actually executes.

  4. Retrieve

    Memory is read by coordinate and by weighted search across the cell's six faces. Hebbian co-activation edges exist alongside this, but the retrieval-side consumer is off by default.

  5. Persist

    The result is written back as a six-face voxel. Edges strengthen. Unused memory metabolises and decays.

How we hold ourselves to it

The lab is built to catch us being wrong.

FALSIFIABILITY

Pre-registered predictions

The Test Bench is an append-only ledger. A prediction is registered with its kill criteria before the run. Calibration is tracked over time, and a failed prediction stays in the record.

INDEPENDENCE

Model-agnostic verdicts

Scoring is calibrated per embedding model against a fixed baseline corpus, so a verdict is reported in σ above baseline rather than a hardcoded cosine cutoff. Swap the model; the verdict still means the same thing.

AUDITABILITY

Exportable traces

A full cognition run exports as a document: every stage, every score, every memory read and write, with coordinates. It is designed to be handed to someone whose job is to disbelieve it.
